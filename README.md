## About The Project

**Sweet Crumbs Bakery** is a bakery website project created to showcase a welcoming digital experience for bakery lovers. Its visual direction focuses on presenting bakery products in an appealing, organized, and user-friendly way.

## Features

- Elegant bakery-inspired presentation
- Product-focused website layout
- User-friendly navigation
- Responsive design goals
- Attractive visual styling
